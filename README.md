# 📊 Finance Analysis Dashboard | Power BI

A professional **Finance Analysis Dashboard** developed in Microsoft Power BI to analyze financial transactions, customer behavior, transaction performance, fees, taxes, and year-over-year (YoY) trends.

The dashboard consists of two interactive pages: **Overview Analysis** and **Transactions**, providing both high-level business insights and detailed transaction-level analysis.

---

## 📌 Dashboard Overview

### 🔹 Overview Analysis

The Overview page provides a complete summary of financial performance through interactive KPIs and visualizations.

**Key KPIs:**
- 💰 Total Amount
- 🔄 Total Transactions
- 📈 Average Transaction Amount
- 💳 Total Fees
- 🧾 Total Tax

**Analysis Included:**
- Total Amount by Month
- Transaction Status Analysis
- Customer Segment Analysis
- State-wise Transaction Analysis
- Gender-wise Analysis
- Transaction Type Analysis
- YoY Performance Comparison

### 🔹 Transactions

The Transactions page provides detailed transaction-level information for deeper analysis.

**Details Included:**
- Transaction ID
- Customer Name
- Transaction Date
- Transaction Type
- Transaction Status
- Gender
- Customer Segment
- State
- Total Amount
- Total Fees
- Total Tax

---

## 🗃️ Data Sources

The project uses two primary tables:

### Finance Transactions
Contains transaction-related information such as transaction date, type, status, amount, fees, tax, and bank charges.

### Customers
Contains customer information such as customer name, gender, customer segment, occupation, and state.

### Date Table
A dedicated Date Table was created for time-based analysis, including **Year, Month, Quarter, and Month Number**, supporting time intelligence and YoY calculations.
